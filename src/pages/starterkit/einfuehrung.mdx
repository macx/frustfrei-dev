## Neue Website erstellen

Du hast deine neue Website ruckzuck erstellt. Richte dein Projekt direkt über das [Terminal](/dokumentation/entwicklung/terminal) deines Betriebssystems ein oder händisch über Visual Studio Code.

<Tabs>
  <TabItem label="Terminal">
    <Steps>
      1. Öffne das Terminal auf deinem Computer.

         Das Terminal startet in der Regel in deinem Benutzerverzeichnis `~/`. Wenn du das Projekt an einem anderen Ort installieren möchtest, navigiere mit `cd` dorthin. Wie das funktioniert, erfährst du im Hilfstext [Aktuellen Pfad kopieren](/dokumentation/entwicklung/terminal#aktuellen-pfad-kopieren).

      2. Führe im Terminal den folgenden Befehl aus, um deine Website zu erstellen:

         ```shell
         npm create website-starterkit@latest
         ```

      3. Folge den Anweisungen, um das Projekt einzurichten.

         <Callout>
           Wähle **Neuen Ordner anlegen**, damit das Starterkit einen Ordner für dich erstellt. Nutze **Im aktuellen Verzeichnis**, wenn du dich bereits im gewünschten Projektordner befindest.
         </Callout>
    </Steps>

  </TabItem>
  <TabItem label="Visual Studio Code">
    <Steps>
      1. Erstelle dir auf deiner Festplatte einen neuen Ordner für dein Projekt.

      2. Öffne Visual Studio Code und wähle den neuen Ordner über `Datei` > `Ordner öffnen`.

      3. Zeige nun das Terminal in Visual Studio Code über das Menü `Anzeige` > `Terminal` oder `Terminal` > `Neues Terminal` an.

      4. Führe im Terminal den folgenden Befehl aus, um deine Website zu erstellen:

         ```shell
         npm create website-starterkit@latest
         ```

      5. Folge den Anweisungen, um das Projekt einzurichten.

         <Callout>
           Wenn du gefragt wirst, wo das Projekt gespeichert werden soll, wähle die Option **Im aktuellen Verzeichnis**.
         </Callout>
    </Steps>

  </TabItem>
</Tabs>

## An der Website arbeiten

Bereit loszulegen? Öffne deinen Projektordner in Visual Studio Code und starte den Entwicklungsserver. Gib dazu einfach diesen Befehl im Terminal ein, um deine Änderungen live im Browser zu sehen:

```shell
npm run dev
```

Falls dabei etwas schiefgeht, findest du Lösungen für häufige Probleme auf der Seite [Fehler beheben](/dokumentation/entwicklung/troubleshooting).
